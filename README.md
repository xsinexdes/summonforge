# SummonForge
Plugin Paper 1.21.1 (Java 21). Compilación: `mvn -B clean package` (GitHub Actions: .github/workflows/build.yml).
Requiere (opcional pero recomendado) el plugin BetterModel. Estado y siguiente paso: `_PROGRESO/ESTADO.md`.

Prueba rápida: `/inv` → "Instalar contenido de ejemplo" → `/inv boss spawn bestia_ceniza` → matarlo (suelta el pergamino)
→ clic derecho al pergamino → Shift+F para invocar → F para habilidad 1 → `/inv yo` para subir de nivel.

## Comandos
/inv (menú maestro) · /inv yo · invocar · despedir · habilidad N · teclas · talentos · bestiario
Admin: ejemplos · dar · boss spawn|kill · spawn set · probar · evento · cine · validar · estado · rescue · dummy · modelos · reload
